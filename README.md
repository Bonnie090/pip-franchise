# Pip Has a Plan!

An original children's entertainment franchise for ages 4–8, built around **Pip**, a 5-year-old fox who draws a plan for everything and charges ahead before he's finished drawing it.

Pip comes from the workbook *Trace & Learn with Pip!* by Bonnie McCain James.

## Read it

- **[Pip Franchise Bible.html](Pip%20Franchise%20Bible.html)**: the full franchise bible. Download the file and open it in a browser to read it with pictures. GitHub shows HTML files as plain code.

## Folders

- `Visuals/`: model sheet, lineups, logo concept, Plan Vision frame
- `Visuals/Episode 1 animatic/`: storyboard frames for Episode 1
- `Animatic/Motion tests/`: first real animated clips (MiniMax H3 chosen as the animation model)
